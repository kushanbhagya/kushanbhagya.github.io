## 🔐 Highlight Projects

### 🧪 Cybersecurity Home Lab
A simulated attack-and-defense environment built for hands-on penetration testing practice.
- **Tools:** Kali Linux, Metasploit, Nmap, Apache
- **Focus:** Real-world pentesting workflows and defensive techniques

### 🔍 Malicious URL Detector *(ML Project)*
A machine learning model that classifies URLs as phishing or malicious.
- **Techniques:** Feature engineering, classification algorithms
- **Goal:** Automate threat detection for web-based attacks

### 🕵️ Phishing Simulation Tool *(Educational)*
Demonstrates phishing attack simulations for awareness and training purposes.
- **Purpose:** Security education and ethical hacking practice
